# TextEditor

A minimal text editor in C

## Compatibility

- **Only Compatible with Unix-like systems**
- In Windows, you need to install bash: [Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/about)

## Installation

1. Clone the repository in your desired folder:
2. Open the folder in the termnal
3. run the commands:
     ~make
     ~./sanju <your filepath>
4. if make is not recognized
      ~sudo apt update
      ~sudo apt install make
      ~make --version
